# TaskFlow – Gestionnaire de tâches
-Application web de gestion de tâches développée avec React et Vite.js.
## Technologies utilisées
-React
-Vite.js
-React Router DOM
## Installation et lancement
## Prérequis
-Node.js installé sur la machine
## Étapes
-Cloner le dépôt : git clone <git@github.com:hamid-Umar/taskflow.git>,
-Installer les dépendances : npm install,
-Lancer le serveur de développement : npm run dev,
-Ouvrir dans le navigateur : http://localhost:5173
## FonctionnalitésAffichage des tâches sous forme de cartes
-Ajout de nouvelles tâches via un formulaire
-Persistance des données dans le localStorage
-Navigation vers la page de détail de chaque tâche
-Hook personnalisé useLocalStorage pour la persistance
